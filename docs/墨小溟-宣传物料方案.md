## 1. 视觉策略总纲

### 1.1 调性三词（与柔光系统一致）

**治愈（Healing）· 平静（Calm）· 克制（Restrained）**

- 不抢戏、不炫技；动效只为「让人读懂下一步」，不为表演。
- 光泽是「晨光透过纱帘」的柔，不是「金属反光」的硬。

### 1.2 声音护栏（写任何文案前先读，违反即废稿）

产品本身的「四不」是品牌人格底线，宣传文案绝不能越过：

- ❌ 禁止话术（碰一条就废）：想开点 / 别想太多 / 你要坚强 / 振作起来 / 时间会治愈一切 / 都会好起来的 / 别哭了 / 你太敏感了 / 我理解你 / 你应该……
- ✅ 正确语气：短句、具体、先接情绪再接事实；给「现在就能做的一个动作」，不是一份说明书。
- ✅ 正确姿态：无评判的情绪容器——不说教、不贴标签、不空洞安慰、不做诊断。

> 反面教材（绝不能用）：「别难过啦，都会好起来的」「你要坚强一点」——这正好是产品最反对的话，发出去等于自己打脸。

### 1.3 配色系统（直接来自设计 Token，全渠道统一）

| 角色 | 色值 | 用法 |
|---|---|---|
| 页面奶油底 | `#FFF8F0` | 主背景，温暖不冷 |
| 卡片暖白 | `#FFFBF7` | 卡片 / 手机界面底 |
| 强调淡紫白 | `#F6EFF7` | 语音盒 / 高亮块 |
| 品牌紫（结构渐变） | `#B8A9E8 → #9E8CD8` | 主按钮 / 光晕 / 主视觉 |
| 录音活态暖橙 | `#FFB88C` | 「按住说」脉冲 / 活态指示 |
| 平静薄荷绿 | `#A8D8C8` | 完成 / 安抚点缀 |
| 三级墨色文字 | `#3A3A3A / #6B6478 / #9A93A6` | 主 / 次 / 弱文（不用纯黑） |
| 暖陶土（风险） | `#C98A7A` | 仅安全弹窗，宣传中极少用 |

> 关键：宣传图背景一律走「奶油白 / 淡紫白」，**不要黑底、不要高饱和撞色、不要荧光**。黑底会直接破坏「治愈平静」的调性。

### 1.4 质感 / 圆角 / 字体 / 留白

- **光效**：分层径向光晕（暖紫 60% 50% @ 50%30% + 暖橙 50% 40% @ 70%75%），模拟「被光包裹」；柔光多层阴影（低饱和紫），不用硬投影。
- **圆角**：大圆角（卡片 24px、大弹层 32px、按钮 pill），温柔不尖锐，呼应产品组件语言。
- **字体（中文）**：标题用偏治愈的手感体（霞鹜文楷 / 思源宋体 / 站酷快乐体圆）；正文用苹方 / 系统无衬线。英文用圆体 / 手写感（e.g. Quicksand / Baloo 2）。
- **留白**：大量呼吸感留白，单图信息 ≤ 3 个重点；宁空勿满。
- **情绪可视化原则**：用「色块 / 光晕 / 波形 / 流动节点」表达情绪起伏，**绝不用情绪分数、等级、曲线图**（产品本身禁止情绪分数，宣传也不能暗含「给你打分」）。

## 2. 宣传图构图思路 × 视觉元素 × 设计风格（按图型给方案）

### 2.1 主视觉 Hero（小红书竖版封面 1080×1440，3:4）

- **构图**：上 1/3 柔光留白 + 漂浮的紫色小墨鱼 IP 与光晕 → 中部手机界面（真机感，显示「按住说」+ 一张情绪卡片）→ 下部 slogan「说出来，就轻一点」+ 一句钩子（如「没人听的时候，它都在」）。
- **视觉元素**：云朵水母 / 小墨鱼（深海紫）、手机界面截图、暖橙「按住说」脉冲按钮、漂浮半透明情绪卡、柔光气泡。
- **风格**：奶油白渐变底 + 淡紫光晕，大圆角卡片，柔和阴影，治愈克制。
- **文案落点**：主标题 slogan；副标题一句话痛点钩子；底部小字「语音情绪复盘 · 无账号 · 本地优先」。

### 2.2 痛点共鸣图（情绪重量对比，1080×1440）

- **构图**：左右分屏隐喻——左「憋着」：人弓着背、头顶一团缠绕的暗色情绪线，色调偏闷；右「说出来」：同一个人轻盈漂浮、身边亮起细小彩色情绪光点，色调转暖紫。中间一道极淡的过渡光。
- **视觉元素**：缠绕情绪线（不用文字标签）、发光情绪节点、同人物前后对比、柔光过渡。
- **风格**：左冷右暖的渐进，不写「before/after」字样，用画面本身说话；底部一句「有些话，说不出来也得有个地方放」。
- **价值落点**：把「情绪堵着 vs 被接住」拍成画面，比写 100 字更戳人。

### 2.3 功能拆解 Carousel（小红书 9 图，每图 1080×1440）

九宫格逐张讲清功能，每张一个重点 + 一句人话：

1. **只一个动作**：手机 + 按住说按钮 → 「不用写，按住就说」。
2. **情绪被接住**：IP 环抱光晕 → 「不评判、不说教，先接住」。
3. **一张情绪卡片**：卡片特写 → 「说完，自动帮你收好这一刻」。
4. **微小行动**：行动卡 → 「不是大道理，是现在就能做的一个小动作」。
5. **情绪时间线**：流动节点 → 「你的心情，变成一条看得见的线」。
6. **周报**：周报卡 → 「一周辛苦了，看看这周怎么过来的」。
7. **月度复盘**：月报卡 → 「一个月的情绪，轻轻收成一页」。
8. **安静陪伴**：静谧场景 → 「不想说的时候，安静待着也好」。
9. **隐私本地优先**：锁 + 本地图标 → 「不设账号，数据先在你自己设备里」。

- **风格**：统一奶油底 + 单色焦点（每张只点亮一个功能色），结尾图回扣 slogan。

### 2.4 场景氛围图（深夜 / 通勤 / 独处，1080×1440 或方图）

- **深夜床头**：暖灯下人坐着握亮屏手机，窗外月色，柔紫环境光 → 钩子「深夜那些翻来覆去，说出来就轻了」。
- **通勤地铁**：车窗倒影 + 耳机 + 手机亮屏 → 「路上那点堵，说出来再下车」。
- **独处一角**：沙发 / 咖啡角落，手机轻放，IP 在旁 → 「一个人也能好好接住自己」。
- **风格**：局部、不露脸或背影，氛围感优先；不拍「痛苦表情」，拍「被温柔接住的安静」。

### 2.5 海外极简主图（Instagram 1:1 / 4:5，Pinterest 2:3）

- **构图**：居中手机 + 一道柔波声波 + 单只紫色小水母图标，大量负空间，留白处给英文 slogan。
- **视觉元素**：极简声波、单色 IP、奶油 + 淡紫背景、精致柔阴影。
- **风格**：clean / minimal / premium self-care，比小红书更克制、更「产品感」；用色块而非真人场景。
- **英文 slogan 落点**：「Say it out loud. Feel a little lighter.」

## 3. 动图 / 视频方案（静态之外的动态表达）

### 3.1 按住说闭环 GIF（核心卖点动图，6–8s 循环）

- 序列：手指按住暖橙按钮 → 波形一圈圈扩散（活态） → 松开 → 一张情绪卡片从底部柔光浮出 → 卡片上「微小行动」小字一闪 → 回到待机。
- 作用：6 秒讲清「按住说 → 被接住 → 拿到一个动作」完整闭环，比静态图信息密度高。

### 3.2 情绪时间线流动（15s）

- 时间线上节点依次亮起、流动，配色随情绪变化（喜悦暖橙 / 委屈淡紫 / 疲惫雾蓝），最后收成一页月报。
- 作用：直观展示「情绪变成看得见的线」，强化差异化。

### 3.3 Reels / Story 脚本（TikTok / IG Reels，9:16，15–30s）

- 0–3s：痛点钩子字幕「那些说不出口的，怎么办」+ 闷色画面。
- 3–10s：按住说动效 + 卡片浮出 + 旁白「说出来，就轻一点」。
- 10–20s：3 个功能快切（时间线 / 周报 / 本地隐私）+ slogan。
- 20–30s：CALL TO ACTION「搜索『墨小溟』，先说一句试试」+ 柔光收尾。

## 4. 配套笔记文案

> 通用护栏：所有文案不出现 §1.2 禁止话术；不暗示「治愈疾病 / 替代专业帮助」；隐私表述准确（本地优先 + 录音可关，不写「完全不出本机」）。

### 4.1 小红书笔记 ×3 角度

#### 角度 A · 痛点共鸣（最易爆，情绪价值优先）

- **吸睛标题库**：
  1. 那些憋了一整天的情绪，我终于找到地方放了
  2. 不是矫情，是没人接得住我的那句话
  3. 深夜翻来覆去？试试把它说出来
  4. 高敏感的人，需要一个不评判的容器
- **正文**：
  > 你有没有过这种时候——心里堵着一团说不清的东西，想跟人讲，又怕被说「你想开点」「别想太多」。
  > 后来我用一个叫墨小溟的小 app：不用写，按住说就好。它不劝你坚强，也不给你贴标签，就安安静静把这一刻接住，再递给你一个「现在就能做的小动作」。
  > 说完那一秒，真的会轻一点。
  > 它不设账号，数据先在你自己手机里；连录音都能关掉只走本地识别。
  > 适合一个人扛着、又不想被说教的人。
- **功能亮点**：按住说 · 无评判接住 · 微小行动卡 · 本地优先隐私
- **目标人群**：高敏感人群（HSP）、独居青年、深夜 emo 党、被说教劝退的倾诉者
- **使用场景**：睡前翻来覆去 / 委屈憋着 / 通勤路上堵得慌 / 不想打扰别人又想说
- **解决的价值**：给无处安放的情绪一个「不被评判」的出口；说出来本身就被接住，不用等别人懂
- **话题标签**：#情绪价值 #高敏感人群 #自我疗愈 #治愈系app #说出来就轻一点 #深夜emo #情绪记录

#### 角度 B · 功能种草（清晰展示功能，理性种草）

- **吸睛标题库**：
  1. 只用「按住说」，它帮我把乱糟糟的情绪理顺了
  2. 一个动作的情绪复盘 app，治好了我的反刍
  3. 把心情变成一条线，我终于看懂自己了
  4. 不设账号的情绪笔记本，隐私党狂喜
- **正文**：
  > 试了一周墨小溟，说说它到底能干什么（不吹，照实讲）：
  > ① 按住说——语音倾诉，不用打字；② 说完自动生成一张情绪卡片，把这一刻收好；
  > ③ 还给一个「微小行动」，不是大道理，是 30 秒能做的小动作；
  > ④ 情绪时间线，把每天的心情连成一条看得见的线；
  > ⑤ 周报 + 月度复盘，看自己这一阵怎么过来的；
  > ⑥ 不想说的时候有「安静陪伴」，就陪你待着。
  > 最戳我的是隐私：不设账号，记录先在你自己设备里，录音也能关。
- **功能亮点**：情绪卡片 / 时间线 / 周报月报 / 安静陪伴 / 本地隐私
- **目标人群**：爱记录复盘的人、自我成长爱好者、隐私敏感用户、反刍脑补型
- **使用场景**：每天睡前一句复盘 / 一周结束看周报 / 情绪反复时回看时间线
- **解决的价值**：把模糊的情绪变成可回看的结构；看清自己的模式，而不是被情绪拖着走
- **话题标签**：#情绪复盘 #好用的app推荐 #自我成长 #效率工具 #隐私保护 #时间线记录

#### 角度 C · 人群精准（锁定某类人，强代入）

- **吸睛标题库**：
  1. 给独居打工人的晚安：今晚的情绪，它帮你收着
  2. 备考 / 考研人，需要一个不说话的树洞
  3. 异地 / 失恋后，我把心事都讲给了它
  4. 社恐的表达练习：先对一个不评判的存在说
- **正文**：
  > 独居第 N 年，最难的不是一个人住，是「想说点什么，却找不到人」。
  > 墨小溟像个不睡觉的树洞：凌晨两点也能按住说，它不会已读不回，也不会回你一句「早点睡」。
  > 它只是把你的委屈、疲惫、偶尔的开心，轻轻接住，再递给你一个今晚能做的小动作。
  > 说出来，真的会轻一点。
- **功能亮点**：随时倾诉 / 不评判 / 微小行动 / 安静陪伴
- **目标人群**：独居青年、异地恋 / 失恋、备考压力、社恐、轮班 / 熬夜党
- **使用场景**：凌晨失眠 / 加班后回家 / 考前焦虑 / 想说又无人可说
- **解决的价值**：填补「无人可说」的空档；情绪有了去处，不再半夜反复想
- **话题标签**：#独居生活 #打工人解压 #异地恋 #考研焦虑 #社恐日常 #树洞app

## 5. 落地清单 & 自检（发布前过一遍）

### 5.1 视觉自检

- [ ] 背景是否为奶油白 / 淡紫白，无黑底、无高饱和撞色、无荧光？
- [ ] 是否用「光晕 / 波形 / 节点」而非「分数 / 曲线」表达情绪？
- [ ] 圆角是否大圆角（卡片≥24px、按钮 pill），阴影是否柔光多层？
- [ ] 单图信息是否 ≤ 3 个重点，留白是否充足？
- [ ] slogan 是否统一「说出来，就轻一点」？

### 5.2 文案自检（红线）

- [ ] 是否出现任何 §1.2 禁止话术（想开点 / 别想太多 / 你要坚强 / 时间会治愈一切 / 别哭了…）？→ 有则废。
- [ ] 是否暗示「治愈疾病 / 替代专业帮助」？→ 有则改，保留「不是心理咨询、不做诊断」边界。
- [ ] 隐私表述是否准确（本地优先 + 录音可关），未写「完全不出本机」？
- [ ] 语气是否「先接情绪再给动作」，而非说教 / 贴标签？
- [ ] 目标人群 / 使用场景 / 解决价值是否三者齐全、不空泛？
