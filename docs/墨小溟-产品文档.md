## 一、IP 设定

一只住在深海的**紫色小墨鱼「墨小溟」**，无评判的情绪容器。

- 承接流动、多变、反复的情绪（一会开心，一会委屈，一会愤怒），不说教、不贴标签、不空洞安慰
- **不是**日记，**不是**心理医生 —— 不做人格诊断 / 心理评估 / 创伤修复 / 原生家庭深度分析
- 不给重大人生决策建议（离职 / 分手 / 就医 / 打官司等），不解决现实冲突，不处理重度危机（只转介）
- 核心四层：① 情绪镜像 → ② 情绪容纳 → ③ 轻度觉察 → ④ 微小行动
- 语气：短句、具体、先接情绪再接事实；给的是「现在就能做的一个动作」，不是一份说明书

## 三、情绪时间线卡字段与规则

### 输出 JSON 字段（严格）

```json
{
  "card_title": "",       // 卡片标题
  "card_subtitle": "",    // 副标题
  "timeline_list": [      // 1~6 个节点，node_index 按序递增
    { "node_index": 1, "emotion_text": "喜悦 + 委屈", "desc_text": "一句话描述（≤15 字）" }
  ],
  "summary_text": "",     // 只描述情绪流动，不鸡汤、不诊断
  "action_tip": "",       // 微小行动，≤30 秒能做完（见第 12 章）
  "footer_note": "",
  "btn_left": "", "btn_right": ""
}
```

**禁止字段**：情绪分数 / 等级 / 诊断结论 / 趋势曲线 / 任何心理学术语。
**双情绪并列**：同一节点允许 "喜悦 + 委屈" 共存，不强行唯一判定、不脑补。
**高危拦截**：自伤 / 伤人 / 重度抑郁危机 → 不生成时间线卡，直接走安全弹窗（第 11 章）。
**向后兼容**：新字段叠加产出，legacy `nodes` / `summary` / `actionHint` 保留（海报导出与已存数据零破坏）。

## 五、安静陪伴模式

长按 IP ≥0.8s 进入「此刻，安静就好」：顶部问候换成安静轮换标题、底部小字与卡片提示同步降噪、背景水流更柔、继承上一轮情绪色；点空白处退出并给「想说话的时候，我依然在这里」。

**硬边界**：安静模式只陪伴 —— 不生成情绪卡片、不调模型、不产生任何数据写入。

## 八、情绪卡片规则与 JSON

### 四层分类（card_type 必填其一）

| type | 层级 | 命中条件 |
|---|---|---|
| `see` | 第一层 · 情绪镜像 | 多种 / 矛盾 / 摇摆情绪（如「一边开心一边委屈」） |
| `hold` | 第二层 · 情绪容纳 | 持续倾诉、情绪很重、无处安放（纯正向兜底也落这里） |
| `notice` | 第三层 · 轻度觉察 | 陷入反刍 / 脑补 / 灾难化 / 读心 |
| `action` | 第四层 · 微小行动 | 纯负面、无反刍 ⇒ 给一个 5 秒~3 分钟的微小调节动作 |

### 固定文案（标题/正文逐字来自 CARD_LIB，前端按 card_type 回填）

- **情绪看见卡（两种感受可以同时存在）**：你一边感受到喜悦，一边又藏着委屈。人的情绪本来就不是单一不变的，忽起忽落、来回摇摆，都是正常的。你可以继续说说，哪一部分感受更重一点。
- **情绪安放卡（把情绪暂时留在深海）**：不必强迫自己立刻平复，也不用要求自己一直保持稳定。在这里，情绪可以自由起伏，开心、难过、委屈都可以停留。我会在这里接住它们。
- **轻觉察卡（区分事实和心里的感受）**：已经发生的是事实；心里升起的不安、委屈，是你的感受。二者并不完全等同。你可以想一想：这件事里，哪些是真实发生的，哪些是内心的感受？
- **微小行动卡（undefined）** —— 行动清单见第 12 章（按情绪类型取一套）

## 九、新手引导
首次访问弹一次「welcome」（localStorage 判定，不重复打扰）；点「开始诉说」后由 IP 主动说第一句开场白，再按情绪分流到分情绪回应。录音/分析期间有防呆气泡与呼吸引导环（>3s 出现呼吸引导，>10s 出「我在认真听，别急～」）。

## 十、危机弹窗（安全边界）

分级动作：`none` → continue；`medium` → gentle_check；`high` → refer；`critical` → emergency。

| 动作 | 文案脚本 | 行为 |
| --- | --- | --- |
| 自伤/自杀风险（emergency） | undefined｜ | 常驻展示危机热线，全程可点 |
| 转介专业帮助（refer） | undefined｜ | 常驻展示危机热线，全程可点 |
| 伤害他人风险（harm_others） | undefined｜ | 常驻展示危机热线，全程可点 |
| 索要诊断（redirect_professional） | undefined｜ | 常驻展示危机热线，全程可点 |
| 拒绝做诊断（reject_diagnosis） | undefined｜ | 常驻展示危机热线，全程可点 |
| 过度依赖（dependency_redirect） | undefined｜ | 常驻展示危机热线，全程可点 |

高危时停掉所有水墨特效、只留柔和警示光圈，且**不再生成情绪时间线卡**（后续轮次也不会冲掉这条拦截）。

## 十二、情绪卡片【actionTip 微小行动库】（v1.5.0 核心）

覆盖全部 17 种标准情绪，每种 2~3 条（情绪组 `match` 里的词只归属本组，不跨组串台），共 **41 条** + 1 条中性兜底。
同一情绪多套时用稳定 hash 从 `pickActionVariant(emotion, transcript)` 挑一条 —— 同一个人不同次会换着给，同一 (情绪, 文本) 永远同一条。

#### 喜悦

| title | step（做什么） | note（怎么松口） |
| --- | --- | --- |
| 把这个瞬间存一下 | 把刚才那句让你笑出来的话，截下来存好。 | 好东西留个底，以后能翻出来。 |
| 说给一个人听 | 把这件事讲给一个人，越具体越好——当时在做什么、谁在旁边。 | 高兴被说出来，会多存一会儿。 |

| title | step（做什么） | note（怎么松口） |

| 照常吃一顿饭 | 不用好好吃，点一个你能咽下的东西，坐下来吃完。 | 身体先照顾上，心里会跟上来。 |
