# 墨小溟 · 柔光设计系统（Soft-Light Design System）

> 版本：v1.0 草案 ｜ 适用：墨小溟 v1.8+ 交互组件审美升级 ｜ 作者：九思
> 一句话定位：**在现有奶油白 + 柔紫品牌底子上，用「柔光层级 + 触感内高光 + 弹性微交互」把"能用"升级成"想一直用"。**

---

## 0. 这份方案能直接怎么用

- **设计 Token**（§2）= 一段可直接粘进 `styles.css` `:root` 的 CSS 变量，替换现有那套。
- **组件规范**（§3）= 每个真实组件（按钮/卡片/开关/导航/弹层…）的"新 CSS + 微交互"，标了 `可直接替换` 的代码块。
- **预览页**（`组件预览.html`）= 同款真实的、可点可看的渲染，能直接抄 CSS、能比对"当前 vs 柔光"。
- **落地路线**（§4）= 分 3 期迁移，不一次性动 99KB 样式，避免回归。

---

## 1. 设计诊断：现在为什么"显得基础"

把现有 `styles.css` 的视觉基线和 2025–2026 成熟实践对齐后，问题很具体（不是"不够好看"，是有结构性短板）：

| 维度 | 现状（v1.7.9） | 为什么显"基础" | 柔光方案对策 |
|---|---|---|---|
| **表面（Surface）** | 卡片全用纯白 `#FFFFFF`，页面是奶油白 `#FFF8F0` | 白卡浮在奶油底上只有"色差"，没有"材质感"；纯白显得平、冷、像没设计 | 染色中性色：表面用**暖白 `#FFFBF7`**，强调块用**淡紫白 `#F6EFF7`**，让层级靠"材质"而非纯色差 |
| **阴影（Elevation）** | 只有 2 档单层阴影 `--shadow / --shadow-sm` | 单层软阴影＝"飘"，没有"放上去/按下去"的体感，缺乏纵深 | 4 档**柔光多层阴影** + **内高光**（`inset 0 1px 0 #fff`），可点击面立刻有"立起来"的触感 |
| **圆角（Radius）** | 只有 1 个 `--radius:20px` | 按钮、卡片、输入框全一个弧，缺乏"重要性阶梯"的视觉节奏 | 圆角阶梯 `sm12 / md18 / lg24 / xl32 / pill`，按钮用 pill、卡片用 lg，节奏分明 |
| **主按钮** | 纯色 `--primary` 填充，按压只 `scale(.975)` | 平涂色块像"占位按钮"，没有"这是主操作"的高级感 | 柔紫**结构渐变** + 内高光 + 按压形变（scale + 下沉阴影 + 提亮），像一颗"可捏的糖" |
| **开关 Switch** | 灰色轨道 + 小白点，无质感 | 像系统默认控件，没有品牌调性 | 开启态**渐变轨道** + 拇指带高光阴影 + 弹性滑动 |
| **底部导航** | 全宽毛玻璃条 + 顶边线 | 像"工具栏"，侵占感强，不轻盈 | **悬浮玻璃药丸**（底部居中、圆角、抬升），激活项用滑动胶囊指示 |
| **微交互** | 基本只有 `transform:scale` | 点击反馈单一，没有"活"的感觉 | 按压形变 + 状态淡入 + 弹性进出 + 数字滚动 + 滑动提示，且**只服务信息层级**（克制） |
| **弹层** | 居中/全屏遮罩，卡片单层阴影 | 模态感重、像"打断"，和"温柔承接"调性有张力 | 底部**玻璃抽屉** + 弹性滑入 + 环境光晕，把"打断"变成"轻轻托起" |

> 诊断结论：**品牌方向（治愈/平静/克制）已经对，缺的是"材质与层级"的执行细节。** 不需要推翻重来，是把"平面贴图"换成"有光、有影、有触感"的组件语言。

## 2. 设计 Token（可直接粘贴进 `:root`）

### 2.1 调性三词
**治愈（Healing）· 平静（Calm）· 克制（Restrained）**
- 不抢戏、不炫技；动效只为"让人读懂下一步"，不为表演。
- 光泽是"晨光透过纱帘"的柔，不是"金属反光"的硬。

### 2.2 色彩（沿用品牌，补齐层级）

```css
:root{
  /* —— 页面与表面：染色中性色（暖调，非纯白） —— */
  --bg:#FFF8F0;            /* 页面奶油底（保留） */
  --bg-soft:#FDF3E9;       /* 次级背景（保留） */
  --surface:#FFFBF7;       /* 卡片主表面：暖白，微染色，比页面更"挺" */
  --surface-2:#FCF6EF;     /* 凹陷/次级表面（输入框、分组） */
  --surface-3:#F6EFF7;     /* 强调表面（语音盒、高亮块）淡紫白 */

  /* —— 品牌紫（保留，作为结构渐变） —— */
  --primary:#B8A9E8;
  --primary-deep:#9E8CD8;
  --primary-soft:#F3EDFF;

  /* —— 语义点彩（保留，调柔） —— */
  --orange:#FFB88C;        /* 录音/活态 */
  --mint:#A8D8C8;          /* 平静/完成 */
  --blue:#A8C8E8;          /* 安抚 */
  --danger:#C98A7A;        /* 风险/危险（暖陶土，不刺眼） */
  --danger-soft:#FFF4F0;

  /* —— 文字：三级墨色（不用纯黑） —— */
  --ink:#3A3A3A;           /* 主文 */
  --ink-2:#6B6478;         /* 次文 */
  --ink-3:#9A93A6;         /* 弱文/占位 */

  /* —— 描边 —— */
  --line:#EFE6DC;                 /* 常规分隔 */
  --card-line:rgba(184,169,232,.18); /* 卡片发丝边 */
}
```

### 2.3 柔光阴影（4 档 + 内高光，替换原有 2 档）

```css
:root{
  /* 内高光：让可点击面"立起来"的关键，叠在阴影上 */
  --hi:inset 0 1px 0 rgba(255,255,255,.9);
  --hi-soft:inset 0 1px 1px rgba(255,255,255,.7);

  /* 4 档柔光多层阴影（低饱和紫，模拟环境光） */
  --shadow-xs:0 1px 2px rgba(94,78,140,.05), 0 2px 6px rgba(94,78,140,.06);
  --shadow-sm:0 2px 4px rgba(94,78,140,.06), 0 6px 16px rgba(94,78,140,.08);
  --shadow-md:0 4px 8px rgba(94,78,140,.07), 0 12px 28px rgba(94,78,140,.12);
  --shadow-lg:0 8px 16px rgba(94,78,140,.10), 0 24px 48px rgba(94,78,140,.16);

  /* 按压态：下沉 + 内阴影（"按进去"的触感） */
  --shadow-press:0 1px 2px rgba(94,78,140,.10), inset 0 1px 3px rgba(94,78,140,.14);
}
```

### 2.4 圆角阶梯（替换单一 `--radius`）

```css
:root{
  --r-sm:12px;   /* 芯片、小标签 */
  --r-md:18px;   /* 输入框、内分组 */
  --r-lg:24px;   /* 卡片（原 20→24，更柔） */
  --r-xl:32px;   /* 大弹层、语音盒 */
  --r-pill:999px;/* 按钮、药丸导航 */
}
```

### 2.5 间距 / 字阶 / 动效 / 玻璃（新增）

```css
:root{
  /* 间距：4px 栅格 */
  --sp-1:4px; --sp-2:8px; --sp-3:12px; --sp-4:16px;
  --sp-5:20px; --sp-6:24px; --sp-8:32px;

  /* 字阶 */
  --fs-xs:12px; --fs-sm:13.5px; --fs-base:15px; --fs-md:16px;
  --fs-lg:18px; --fs-xl:21px; --fs-2xl:26px;

  /* 动效：时长 + 曲线（克制，服务信息） */
  --dur-fast:140ms; --dur:220ms; --dur-slow:340ms;
  --ease-spring:cubic-bezier(.34,1.56,.64,1);  /* 弹性进出/按压 */
  --ease-out:cubic-bezier(.22,1,.36,1);        /* 柔减速 */
  --ease-in-out:cubic-bezier(.65,0,.35,1);

  /* 玻璃（手术式用于临时浮层） */
  --glass-bg:rgba(255,251,247,.72);
  --glass-brd:rgba(255,255,255,.6);
  --glass-blur:18px;

  /* 结构渐变（不是装饰，是"哪里是主操作"的提示） */
  --grad-primary:linear-gradient(135deg,#C3B4EE 0%,#9E8CD8 100%);
  --grad-brand:linear-gradient(135deg,#FFF8F0 0%,#F3EDFF 100%);
}
```

## 3. 组件语言（与真实组件一一对应）

> 每条都标 `可直接替换` 的 CSS。命名沿用现有 class（`.primary`、`.card`、`.switch`、`.tabbar`、`.toast`…），**不改 JS、不改结构，只升级样式与微交互**。

### 3.1 主按钮 `.primary`（可直接替换）
**升级点**：平涂 → 结构渐变 + 内高光 + 按压形变（缩放 + 下沉阴影 + 提亮），像一颗可捏的糖。

```css
.primary{
  display:block;width:100%;padding:15px 18px;margin-top:16px;
  border:0;border-radius:var(--r-pill);
  background:var(--grad-primary);
  color:#fff;font-size:16px;font-weight:600;letter-spacing:.3px;
  box-shadow:var(--shadow-md), var(--hi);
  transition:transform var(--dur) var(--ease-spring),
             box-shadow var(--dur) var(--ease-out), filter var(--dur-fast);
  cursor:pointer;
}
.primary:active{
  transform:scale(.975) translateY(1px);
  box-shadow:var(--shadow-press);
  filter:brightness(1.05);
}
```

### 3.2 次按钮 `.ghost-btn`（可直接替换）
**升级点**：生硬描边 → 暖白表面 + 发丝边 + 内高光，按压有"按下"反馈而非只有缩放。

```css
.ghost-btn{
  display:block;width:100%;padding:13px;margin-top:10px;
  border:1.5px solid var(--card-line);border-radius:var(--r-pill);
  background:var(--surface);color:var(--ink);font-size:15px;
  box-shadow:var(--shadow-xs), var(--hi-soft);
  transition:transform var(--dur) var(--ease-spring),
             box-shadow var(--dur) var(--ease-out), border-color var(--dur);
}
.ghost-btn:active{ transform:scale(.985); box-shadow:var(--shadow-press); }
```

### 3.3 危险按钮 `.danger`（可直接替换）
**升级点**：冷红描边 → 暖陶土淡底 + 柔阴影，警示但不尖锐，契合"温柔承接"。

```css
.danger{
  display:block;width:100%;margin-top:12px;padding:13px;
  border:1.5px solid #EBD0C8;border-radius:var(--r-pill);
  color:var(--danger);font-size:15px;background:var(--danger-soft);
  box-shadow:var(--shadow-xs);
  transition:transform var(--dur) var(--ease-spring), box-shadow var(--dur);
}
.danger:active{ transform:scale(.985); box-shadow:var(--shadow-press); }
```

### 3.4 卡片系列 `.card / .mcard / .set-block / .wk-block`（可直接替换）
**升级点**：纯白平板 → 暖白表面 + 发丝边 + 内高光 + 静止柔和阴影，悬停/按压**轻微抬升**（`translateY(-2px)` + 阴影升档），给"可点"的明确信号。

```css
.card,.mcard,.set-block,.wk-block{
  background:var(--surface);
  border:1px solid var(--card-line);
  border-radius:var(--r-lg);
  box-shadow:var(--shadow-sm), var(--hi-soft);
  transition:transform var(--dur) var(--ease-out),
             box-shadow var(--dur) var(--ease-out);
}
.card:active,.mcard:active{      /* 列表项按压抬升 */
  transform:translateY(-2px);
  box-shadow:var(--shadow-md), var(--hi-soft);
}
```

### 3.5 开关 `.switch`（可直接替换）
**升级点**：灰轨白点 → 关闭态柔和灰紫、开启态**渐变轨道**；拇指带高光阴影，**弹性滑动**。

```css
  background:#E4DCF2;border-radius:var(--r-pill);position:relative;
  transition:background var(--dur) var(--ease-out);outline:none;flex:0 0 auto;
}
.switch input:checked{ background:var(--grad-primary); }
.switch input::after{
  content:"";position:absolute;top:3px;left:3px;width:20px;height:20px;
  border-radius:50%;background:#fff;
  box-shadow:var(--shadow-sm), var(--hi);   /* 拇指高光 */
  transition:transform var(--dur) var(--ease-spring);
}
.switch input:checked::after{ transform:translateX(20px); }
```

**升级点**：细轨道 + 小圆点 → 渐变填充轨道 + 带高光与光环的拇指，拖动更有"捏住"的质感。

```css
.fld__range{ -webkit-appearance:none;appearance:none;width:100%;height:8px;
```

**升级点**：全宽毛玻璃条 + 顶边线（像工具栏）→ **悬浮玻璃药丸**（底部居中、圆角、抬升），激活项用**滑动胶囊指示**，轻盈不侵占。

### 3.8 提示气泡 `.toast`（可直接替换）
**升级点**：奶油底 + 单层阴影 → 玻璃质感 + 内高光 + 弹性滑入，像"轻轻飘出的耳语"。


**升级点**：居中硬遮罩 → **底部玻璃抽屉** + 弹性滑入 + 环境光晕，把"打断"变成"轻轻托起"。以"更新弹窗"为例：

### 3.10 情绪芯片 `.tag / .cchip`（可直接替换）

### 3.12 IP 舞台（`ip-bg` / `.mascot`）—— 保留形象，加环境光
云朵水母形象**不动**（已是产品资产），只在背景加**分层径向光晕**（暖紫 + 暖橙），让舞台有"被光包裹"的纵深，呼应"说出来，就轻一点"的包裹感。

```css
.ip-bg::before{ content:"";position:absolute;inset:0;
  background:
    radial-gradient(60% 50% at 50% 30%, rgba(195,180,238,.28), transparent 70%),
    radial-gradient(50% 40% at 70% 75%, rgba(255,184,140,.18), transparent 70%);
  pointer-events:none; }
```

## 4. 微交互细节（克制，只为信息层级）

| 交互 | 怎么做 | 时长/曲线 | 服务什么 |
|---|---|---|---|
| **按压形变** | `scale(.97)+translateY(1px)` + 阴影转 `--shadow-press` + `brightness(1.05)` | 140–220ms / spring | 确认"可点"，降低误操作 |
| **卡片抬升** | 按压 `translateY(-2px)` + 阴影升档 | 220ms / ease-out | 列表项"可进"信号 |
| **状态切换** | 开关轨道渐变过渡 + 拇指 spring 滑动；tab 胶囊 spring 滑动 + 文字色淡入 | 220ms | 让"开/关""在哪一页"一眼可读 |
| **抽屉/弹层** | 从底部 `translateY(100%)→0` spring 进入 + 遮罩淡入 | 340ms / spring | 把"打断"软化成"托起" |
| **Toast** | `scale(.96)+下移` → `scale(1)+归位` spring | 220ms | 反馈不抢戏 |
| **数字滚动** | 统计/天数用 `requestAnimationFrame` 计数动画 | 400ms / ease-out | 让"进步"被看见（复盘页） |
| **滑动提示** | 保留 `#swipeHint`，加柔光阴影与淡入淡出 | 120ms | 教"左滑退出"不突兀 |
| **环境呼吸** | IP 背景光晕 6s 缓动循环（已有机制，接入新光晕） | 6s | 平静感，不表演 |

> **动效纪律**：单页同时进行的"强调动效"不超过 1 个；进场/退场必有，但位移 ≤ 24px、时长 ≤ 340ms；绝不为了"酷"加无信息意义的动画。

## 5. 落地路线（3 期，避免一次性回归）
